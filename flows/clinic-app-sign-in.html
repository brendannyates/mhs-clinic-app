Build sheet: MHS Clinic sign-in and reads

Two flows give the MHS Clinic app a real per-person sign-in without an Entra app registration. Clinic App · Auth sends a one-time code to the person's own Teams (a Workflows card with the code and a one-tap Sign in button) and swaps a correct code for a session token. Clinic App · Read answers with clinic files only for a live token, and re-checks the person's row on every call, so turning someone off takes effect on their next refresh. The app calls both as text/plain POSTs, and each Response sets Access-Control-Allow-Origin: the same pattern as the IVK eligibility feed.
